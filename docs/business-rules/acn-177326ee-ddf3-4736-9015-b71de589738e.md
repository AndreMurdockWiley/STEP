### Functional description

Marks the product as being in the activation process and advances the Collection Creation workflow. When the `CollectionCreationWF` reaches **State-2** and the **SendToHeaderEnrichment** event is executed, this action updates `ProductActivated` to reflect that activation has started, then triggers the workflow transition that moves the collection forward to the next step (Header Enrichment).

### Functional logic

This section summarizes the configured functional logic captured in the rules inventory. The bullet points below are a concise, human-readable summary of the rule logic.

- **Set activation status**: Set `ProductActivated` = `In Progress`.
- **Advance the workflow**: Trigger the `CollectionCreationWF` state-flow event `SendToHeaderEnrichment` from **State-2** with process note `state2 to next` to transition the collection to the next workflow state.
